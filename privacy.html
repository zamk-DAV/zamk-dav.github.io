모먼개인정보 처리방침

개인정보 처리방침

시행일: 2026년 11월 12일 · 모먼 캘린더, 모먼 체크리스트

이 방침은 dohyun kim이 운영하는 모먼 캘린더와 모먼 체크리스트(이하 "모먼 앱")에 적용됩니다. 특히 사용자가 Google 계정을 연결했을 때 Google 사용자 데이터를 어떻게 다루는지 설명합니다. 모먼 체크리스트의 일반 개인정보 처리방침은 체크리스트 지원 사이트에서도 볼 수 있습니다.

앱에서 처리하는 정보

모먼 앱은 사용자가 직접 입력한 일정, 할 일, 메모, 날짜, 그룹, 완료 상태와 화면 설정을 처리합니다. 앱 자체 계정 가입은 필요하지 않습니다. 기록은 기기에 저장되고, 사용자가 iCloud를 사용하는 경우 본인 Apple 계정의 iCloud 비공개 저장소로 동기화될 수 있습니다.

Google 계정 연결 시 접근하는 데이터

Google 연결은 사용자가 직접 선택하는 기능입니다. 사용자가 허용한 경우에만 다음 데이터에 접근합니다.

  • 이메일 주소 (userinfo.email, openid): 연결된 Google 계정을 앱 화면에 표시하기 위해 사용합니다.
  • Google 캘린더 목록 (calendar.calendarlist.readonly, 모먼 캘린더): 사용자가 어떤 캘린더를 앱에 표시할지 고를 수 있도록 캘린더 이름과 색상을 읽습니다.
  • Google 캘린더 일정 (calendar.events, 모먼 캘린더): 일정을 앱에 표시하고, 사용자가 앱에서 일정을 만들거나 수정하거나 삭제할 때 그 변경을 Google 캘린더에 반영합니다.
  • Google Tasks (tasks, 모먼 캘린더·모먼 체크리스트): 할 일 목록과 할 일을 앱에 표시하고, 사용자가 앱에서 할 일을 만들거나 수정·완료·삭제할 때 그 변경을 Google Tasks에 반영합니다.

Google 데이터의 사용 방법

Google 데이터는 위에 적은 앱 기능, 즉 사용자가 자신의 일정과 할 일을 보고 편집하는 기능에만 사용합니다. Google 데이터는 사용자의 동작 없이 변경되지 않습니다. 광고, 마케팅, 사용자 프로필 작성, 신용 평가에 사용하지 않으며, AI·머신러닝 모델을 학습시키는 데 사용하지 않습니다.

Google 데이터의 저장과 공유

모먼 앱은 사용자의 기기에서 Google 서비스와 직접 통신합니다. 개발자가 운영하는 서버로 Google 데이터를 보내지 않으며, 개발자는 사용자의 Google 데이터를 볼 수 없습니다. Google 로그인 인증 정보(토큰)는 기기의 Keychain에 저장합니다. 앱 기능을 위해 가져온 일정과 할 일은 기기 안에 저장될 수 있고, 사용자가 iCloud를 사용하는 경우 같은 Apple 계정의 기기끼리 본인의 iCloud 비공개 저장소를 통해 동기화될 수 있습니다.

Google 데이터를 제3자에게 판매하거나 전달하지 않습니다. 법령에 따라 요구되는 경우는 예외입니다.

Google 연결 해제와 데이터 삭제

앱의 Google 연결 설정에서 연결을 해제하면 기기에 저장된 인증 정보와 해당 계정에서 가져온 데이터를 삭제하고, 그 계정을 다른 Google 연결(캘린더 또는 Tasks)에서 더 이상 쓰지 않으면 Google에 접근 권한 취소를 요청합니다. Google 계정의 서드파티 앱 관리에서도 언제든 접근 권한을 취소할 수 있습니다. 앱을 삭제하면 기기에 저장된 앱 데이터도 함께 삭제됩니다. Google 캘린더와 Google Tasks의 원본 데이터는 Google 계정에 그대로 남으며, Google의 정책에 따라 관리됩니다.

Google API 제한적 사용 준수

모먼 앱이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

광고와 추적

모먼 앱에는 광고, 광고 추적, 제3자 분석 SDK가 없습니다.

문의와 변경 안내

개인정보 관련 문의는 GitHub Issues로 남겨 주세요. 문의는 공개되므로 민감한 정보를 적지 마세요. 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.

Privacy Policy (English summary)

This policy applies to Momen Calendar and Momen Checklist ("Momen apps"), operated by dohyun kim.

Google user data accessed. Only when the user chooses to sign in with Google: email address (to show which account is connected); Google Calendar list (to let the user pick calendars to display, Momen Calendar); Google Calendar events (to display events and to create, edit or delete events at the user's request, Momen Calendar); Google Tasks (to display task lists and tasks and to create, edit, complete or delete tasks at the user's request, both apps).

Use. Google user data is used only to provide these user-facing calendar and task features. It is never used for advertising, marketing, profiling, credit evaluation, or to train AI/ML models.

Storage and sharing. The apps communicate with Google directly from the user's device. No Google user data is sent to or stored on any developer server, and the developer cannot see it. OAuth tokens are stored in the device Keychain. Fetched events and tasks may be cached on the device and, if the user uses iCloud, synced between the user's own devices through their private iCloud storage. Google user data is not sold or shared with third parties, except as required by law.

Revoking access and deletion. Disconnecting Google in the app deletes the stored credentials and that account's fetched data from the device, and revokes the token once no other Google connection in the app uses that account. Users can also revoke access at myaccount.google.com/permissions. Deleting the app deletes its on-device data.

Limited Use. Momen apps' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact. GitHub Issues. Effective November 12, 2026.
